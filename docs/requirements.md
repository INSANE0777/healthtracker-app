# HealthTracker App - Requirements (HT-4)

## Vision
A mobile app that lets users log and review daily health data (steps, weight, heart rate, sleep) and keeps it in sync across devices.

## Functional requirements
1. FR-1 User can create an account and sign in.
2. FR-2 User can log health metrics (steps, weight, heart rate, sleep).
3. FR-3 User can view daily and weekly history with simple charts.
4. FR-4 Data syncs to the backend and is available on every device.
5. FR-5 App can be submitted to the App Store (store listing, privacy policy).

## Non-functional requirements
- Health data is encrypted in transit and at rest.
- Screens load in under 2 seconds on a typical mobile connection.
- WCAG 2.1 AA colour contrast.

## Out of scope for v1.0 (deferred to v1.1)
- Daily push reminders (HT-13)
- Dark mode (HT-14)
- Wearable device sync (HT-15)
